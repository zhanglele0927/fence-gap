
# 围栏缝隙检测原型

从围栏照片中寻找可能的内部缺口或竖向接缝，为现场检查提供线索。

## 输入和输出

输入围栏照片并定位待检区域。输出原图上的可疑区域标记，供复核。

## 如何解读结果

适用于可定位的绿色围栏试验场景。阴影、视角、遮挡和门缝会影响判定，不能用图中标记代替现场量测。
